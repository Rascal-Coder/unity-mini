# 横屏骰子训练场

入口：在团结引擎中打开 `Assets/Scenes/DiceTraining.unity`，或菜单 `Dice Hero > Open Dice Training`，然后进入 Play。
原职业换装预览保留在 `Assets/Scenes/HeroPreview.unity`。训练场已列为构建场景第一项。

## 当前玩法

- 三个职业入口：战士（剑盾）、游侠（弓）、法师（法杖），使用各自 Spine 动作与既有职业外观。不使用 PL。
- 每回合五枚骰子，初始最多掷三次（含第一次）。点击骰子保留，再掷只改变未保留的骰子；可直接攻击。
- 一对、两对、三同、小顺、葫芦、大顺、四同、五同有不同倍率。伤害为 `(基础伤害 + 点数总和 × 2) × (组合倍率 + 契约加成)`，四舍五入。
- 战士近身斩击后归位；游侠三连箭（总伤害分摊，余数保留）；法师发射奥术球和冲击环。攻击阶段禁止重掷与换职业。
- 木桩受击摆动、变色、显示伤害数字；木桩暂不反击。击破后选一项契约，继续挑战血量更高的木桩。
- 契约：基础伤害 +8、每轮掷骰次数 +1（最高 5）、组合倍率 +0.2。掷骰上限达到后该项禁用。
- 更换职业保留训练进度和契约，但清空当前骰子，恢复本回合掷骰次数。这是练习场规则，正式关卡需限制中途换职。
- 支持触摸/鼠标、安全区域、暂停和声音开关；切到后台自动暂停。本版训练进度不存档。

## 分层拼装与遮挡

不是把完整场景贴成一张图。Hierarchy 中 `Dice Battle / Layered training ground` 下的各物件可以独立移动、缩放或替换：

| 层级 | 内容 | 排序方式 |
|---|---|---|
| 01 Far landscape | 远山与天空 | -1000 |
| 02 Walkable ground | 独立地面平台 | -800 |
| 03 Rear props | 三段围栏、后排草石 | 脚底 Y 排序 |
| 04 Actors | 英雄脚底锚点、木桩脚底锚点 | 脚底 Y 排序 |
| 05 Foreground props | 左右草石、小块近景石 | 脚底 Y 排序 |

`BattleDepth` 使用 `SortingGroup`，排序值为 `-脚底世界 Y × 100 + offset`。越靠下越靠前，角色的内部 Spine 绘制顺序保持完整。物件原点放在底部中心；旋转受击表现只作用于木桩视觉子物件。当前英雄与木桩在相同的战斗纵深，投射物使用相邻排序值，近景可以覆盖它们。

第一次完成脚本导入后，编辑器脚本会将部件烘焙为场景中的独立对象；之后不覆盖你的布局修改。若正在导入、场景有未保存修改等原因导致未生成，可以先保存，再使用 `Dice Hero > Bake Training Stage If Missing`。运行时还有相同的分层构建回退。

该阶段地面为单个独立平台部件，未制作可无限平铺的 Tilemap；远山内部山体也未进一步拆分视差层。近景与围栏已经拆开，满足当前固定镜头训练场的遮挡需求。

## 素材与导入

`Assets/Resources/Battle/Art`：远山、地面、围栏、草石、木桩，共五张 PNG。除远山外均带透明通道。裁掉多余透明边距，没有压缩或改写已有角色图集。

`Assets/Resources/Battle/Audio`：掷骰、保留骰子、挥剑、木头命中、弓弦、奥术施法、胜利、按钮，共八段合成 WAV。生成源代码：`Tools/generate_battle_audio.py`。

攻击视觉由 `BattleEffect` 的独立网格生成：斩击弧、箭矢、奥术球、冲击环、命中火花。不依赖联网素材或额外插件。

新增场景 PNG：Sprite / Full Rect / 底部中心原点 / Bilinear / 无 Mipmap / 不压缩 / 最大 4096。新增音效：单声道 PCM，预载解压。新增贴图的导入规则只影响 Battle/Art，不涉及 Assets/Hero。

中文使用 Noto Sans CJK SC，许可证随字体放在 `Assets/Resources/Battle/Fonts/OFL.txt`。素材来源记录见 `Docs/battle-assets-manifest.json`。

## 状态与后续范围

本次按要求没有启动游戏或设备验证。资源和逻辑已接入，最终画面、音量、动画击中时点以及手机触摸手感需你在团结引擎内确认。击中时点目前按攻击动画时长估算；后续可以按每条 Spine 动画的事件精确对齐。

当前交付为训练场原型，尚未包含真实敌人 AI、敌方攻击、失败条件、联网、局内保存或完整自走棋经济系统。
